# T-998: Ortak cihaz kaydı (QR), cihaz listesi/iptal, hızlı kullanıcı değişimi
**Faz:** 4S · **Ajan:** backend · **Bağımlılık:** T-997 · **Dal:** `feat/T-998-shared-devices`
**Amaç (tek cümle):** El terminali/tableti yönetici QR'ı ile tenant'a kaydetmek, iptal etmek ve vardiyada ad + PIN ile hızlı kullanıcı değiştirmek.
**Okuma listesi (≤5):** ADR-026 §7.5–7.7, `docs/spec/07-mobile-offline.md`
**Dokunulacak dosyalar (≤10):** `packages/domain/src/identity/devices.ts`, `apps/web/app/t/[slug]/devices/*`, `apps/web/app/field/switch/*`, testler
**Yapılacaklar:** 5 dk QR; iptal oturumları kapatır; bekleyen iş uyarısı; boşta kilit; audit'e cihaz kimliği.
**Kabul ölçütü:** int: iptal/başka tenant cihazı reddi; e2e iki personel değişimi.
**Kapsam dışı:** Yaka kartı.
**Gerekli inceleme:** security-reviewer.
