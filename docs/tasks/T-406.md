# T-406: Ödemeler ekranı (elle işaretleme, şirket kurulana kadar)
**Faz:** 4S · **Ajan:** backend · **Bağımlılık:** T-404 · **Dal:** feat/T-406-panel-payments → `int/panel-2`
**Amaç (tek cümle):** Aylık tahakkukları ve ödendi/gecikti/bekliyor durumlarını panelde izlemek; ödeme elle işaretlenir, hatırlatma gönderilir.
**Okuma listesi (≤5):** ADR-027 §8
**Dokunulacak dosyalar (≤10):** `packages/db/migrations/0043_*`, `packages/domain/**`, `packages/shared/src/errors.ts`, `apps/web/**`, `scripts/design/port.mjs`, `tests/integration/**`, `docs/**`
**Yapılacaklar:** Dönem tahakkuku (worker, ayda bir), elle ödendi işareti (kayıtlı), gecikme hatırlatma e-postası.
**Kabul ölçütü:** int + piksel karşılaştırması.
**Kapsam dışı:** Ödeme alma (T-405).
**Gerekli inceleme:** security-reviewer.
