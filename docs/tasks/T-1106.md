# T-1106 — Doğal Türkçe ses (EMA Lightning) rehber hoparlörlerinde

**Dal:** `feat/T-1106-dogal-ses`
**Amaç:** Kullanıcı (27 Ekim, 6. iş): "Türkçe doğal konuşan dil … aktif değil, robot ses konuşuyor hâlâ". Yazı → ses hiç kurulmamıştı (Q-129 kararı EMA Lightning; B-129); rehberlerdeki hoparlör cihazın `speechSynthesis` sesini kullanıyordu.
**Dokunulacak dosyalar:** `docs/tasks/T-1106.md`, `docs/changes/T-1106.md`, `services/voice/Dockerfile`, `services/voice/app.py`, `services/voice/fetch_model.py`, `services/voice/requirements.txt`, `services/voice/test_app.py`, `apps/web/lib/voice.ts`, `apps/web/lib/voice.test.ts`, `apps/web/lib/rate-limit.ts`, `apps/web/app/t/*/etkin/actions.ts`, `apps/web/app/t/*/etkin/actions.test.ts`, `apps/web/app/t/*/kalip/sesli-oku.ts`, `apps/web/app/t/*/kalip/adim-rehber.tsx`, `apps/web/app/t/*/kalip/rehber.tsx`, `apps/web/app/t/*/yolculuk/yolculuk.tsx`, `tests/integration/voice/etkin.int.test.ts`.
**Kapsam:**
- Ses servisi (aynı `voice` kapsayıcısı; yeni kapsayıcı/compose değişikliği yok): `/tts` — EMA Lightning 1.1.2 (Apache-2.0), PyTorch 2.14.1 yalnız CPU yapısı; model sabit Hugging Face revizyonundan SHA-256 + boyutla imaja gömülür, `torch.load(weights_only=True)`; çalışırken ağ yok. Q-129 ön çevirisi ("A-3" → "A 3", "7,5" → "7 buçuk"; sayı/birimi modelin normalleştiricisi okur), en çok 400 karakter, tek çalışan + sınırlı kuyruk, aynı metne sabit tohum + 48 cümlelik bellek önbelleği. Model yüklenemezse STT sürer, `/tts` 503.
- Web: `etkinSoyleAction` (Origin + oturum, üyelik + `stock.view`, kullanıcı başına dakikada 30 — `tts` kovası); ortak `useSesliOku` (Türkçede doğal ses, servis yoksa/başka dilde cihaz sesi; iPhone için dokunuşta açılan ortak `<audio>`), üç rehber hoparlörü buna bağlandı.
**Doğrulama:** imaj içi test: yazı → ses → (aynı imajdaki Whisper) yazı "hava" sözcüğünü bulur ve iki model birlikte < 1100 MiB bellek (kapsayıcı sınırı 1280 MiB); servis birim testleri (ön çeviri, WAV, önbellek, kuyruk); web birim testleri (eylem sınırı, istemci yanıt eşlemesi); `pnpm prepush`.
**Risk:** ses imajı büyür (torch CPU ~200 MB tekerlek); yayın arşivi alıcı sınırı (1,5 GiB) içinde. Etkin komut yanıtlarının sesli okunması ve kiracı "Sesli yanıt" ayarı (B-134) bu işte yok.
