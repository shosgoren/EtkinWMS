# T-900: Bağımsız Motive VPS yayını

**Faz:** Pilot · **Ajan:** Codex · **Bağımlılık:** Bağımsız EtkinWMS başlangıcı · **Dal:** feat/T-900

**Amaç (tek cümle):** Yeni Hostinger VPS üzerinde web/worker süreçlerini ayrı Neon veritabanına bağlayıp wms.etkinyazilim.com üzerinden HTTPS ile yayınlamak.

**Okuma listesi (≤5):** Dockerfile, README.md, docs/STATE.md, .dockerignore, apps/web/AGENTS.md.

**Dokunulacak dosyalar (≤10):** `deploy/vps/**`, `README.md`, `docs/STATE.md`, `docs/tasks/T-900.md`, `apps/web/AGENTS.md`, `apps/web/CLAUDE.md`.

**Yapılacaklar:** Web ve worker aynı doğrulanmış imajdan çalışır. Runtime sırları kod dışında ve süreçlere göre ayrı dosyalardadır. Caddy yalnız WMS alt alan adını yayınlar. Kaynak projenin kaynakları değişmez.

**Kabul ölçütü:** Üretim Docker derlemesi, Compose doğrulaması, VPS derin sağlık kontrolünde DB/kuyruk/worker OK, geçerli HTTPS sertifikası ve yetkili DNS kaydında yeni VPS adresi. Bu kart müşteri iş akışlarının tamamlandığını iddia etmez.
