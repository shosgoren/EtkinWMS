## Bulgular → değişiklik
- **Stok girişi / çıkışı / transfer formu** eski T-929 görünümündeydi: formun kendi "Taslağı kaydet" düğmesi + alt çubuk KAYDET (iki Kaydet; telefonda alanların üstüne biniyordu), kutu içinde kutu, düz kutular. → Form kabında formun düğmesi gizli (alt çubuk onu çağırır; kapalılık aynı düğmeden), çerçeve kaldırıldı, alanlar `KalipAlan` + `Typeahead variant="kalip"`, özet kalıp kartı. Aynı ortak düzeltme sevk siparişi, reçete, sayım başlatma formlarına da uygulanır (hepsi `FormEkran kind="form"`); çok formlu ayrıntı ekranları değişmedi.
- **Stok işlemleri listesi:** üstte kesik çizgili "Stok çıkışı" ve "Depolar arası transfer" + alt YENİ (üç giriş). → YENİ → büyük ikonlu tür seçimi (Giriş · Çıkış · Transfer; yetkisiz seçenek kilitli + gerekçe). Tarihler "26.10.2026".
- **Cariler › Arşivli** etkin carileri de gösteriyordu (domain `listParties` `archived` = "dahil et"). → yalnız arşivdekiler; boş arşivde "Arşivde cari yok" + Etkin'e dön (arama hatası metni ve Excel kesik düğmesi yok). Int testi genişletildi.
- **Ürün kartı:** ad "Balonlu naylon …" kesiliyordu; "Tüm hareketler" bağlantısında mikrofon simgesi. → ad ≤3 satır, liste kartı ≤2 satır, telefonda üst çubuk adı ≤2 satır ("Cari k…" → "Cari kartlar"); ok simgesi.
- **Standart bekçisi:** `kural-standart.test.ts` (tek Kaydet, çerçevesiz form, ad kesilmez, Tümü'de mikrofon yok). UI_UX'e yeni ekran kuralı.
