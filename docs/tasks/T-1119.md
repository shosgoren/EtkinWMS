# T-1119 — Belge formlarının içi kalıp tasarımına (B-123)

**Dal:** `feat/T-1119-belge-formlari-kalip`
**Amaç:** Kullanıcı (28 Ekim): "Tüm form alt formlara bak, eksik eski tasarım öğelerine ait bir şey kalmasın." Mal kabul, sevk, üretim, stok fişi ve sayım formlarının İÇİ (ve stok belgesi kartı) eski `@wms/ui` Banner / Button / TextField, kütüphane simgeleri, Typeahead ve Tailwind `control` kutularından arındırılır; kalıp bileşenleriyle yazılır (STANDART §4, ALTIN-KURAL).
**Dokunulacak dosyalar:** `docs/tasks/T-1119.md`, `docs/changes/T-1119.md`, `docs/design/STANDART.md`, `apps/web/app/design/standart.css`, `apps/web/app/t/*/kalip/belge.tsx`, `apps/web/app/t/*/kalip/ico.tsx`, `apps/web/app/t/*/kalip/kap.ts`, `apps/web/app/t/*/kalip/ekran.tsx`, `apps/web/app/t/*/kalip/secim.tsx`, `apps/web/app/t/*/kalip/rehber.tsx`, `apps/web/app/t/*/receipts/receipt-form.tsx`, `apps/web/app/t/*/receipts/receipts-view.tsx`, `apps/web/app/t/*/shipping/shipping-form.tsx`, `apps/web/app/t/*/production/production-form.tsx`, `apps/web/app/t/*/stock/documents/document-form.tsx`, `apps/web/app/t/*/stock/documents/document-card.tsx`, `apps/web/app/t/*/counts/counts-forms.tsx`, `apps/web/messages/tr.json`, `apps/web/messages/en.json`, `tests/e2e/zz-stock-documents.spec.ts`, `tests/e2e/zzz-receiving.spec.ts`, `tests/e2e/zzzz-yolculuk.spec.ts`.
**Kapsam:**
- Ortak (önce kalip/): `kalip/belge.tsx` — `KalipBildirim` (hata `alert`, uyarı/tamam/bilgi `status`; trafik ışığı), `KalipDugme` (ana / ikincil / tehlike, `.kyuk` yükleniyor), `KalipSatirKart`, `KalipFormKap` (ayrıntı kabında `.dzf` kapsamı; tür ve tema `KalipEkran` bağlamından, `kalip/kap.ts`). `KalipSecimAra` (`secim.tsx`): seçenekleri sunucuda aranan alan — aynı alan + aramalı seçim sayfası (200 ms bekleme, eski yanıt yok sayılır, okutma sunucuda çözülür); `KalipSecimSayfasi` `ara` seçeneği. `Ico`/`MicIco` hafif `kalip/ico.tsx`'e taşındı (ekran.tsx yeniden dışa verir; birim testleri kabuk bağımlılığı çekmez). İşlem rehberi (`rehber.tsx`): seçim alanını açmak / seçim sayfasında aramak-kapatmak adımı ilerletmez, seçenek seçmek ilerletir. CSS `standart.css` (kök belirteçler, açık + koyu).
- Formlar: `ErrorNotice` / `LineStatus` / `OperationError` aynı dışa aktarım ve davranışla kalıp görünümünde (`OperationError` hata sesi de çalar); Typeahead → `KalipSecimAra` (stok fişi, üretim reçetesi / emri, sevk siparişi, mal kabul ürünü); ham giriş / textarea → `KalipAlan`; kör sayım onay kutusu → `KalipAnahtar`; eski `control` sınıfı ve dışa aktarımı kaldırıldı; mal kabulün "Teslimi kaydet"i `workflow-primary` (alt çubuk ana işlemi çağırır, iki Kaydet yok).
- Çıkış koruması: React durumundaki seçim / satırlar `data-dirty` verir (stok fişi, reçete, üretim emri, sevk siparişi, sayım; mal kabulde zaten vardı).
- Korunan sözleşmeler: anahtarlı gönderim (`useKeyHolder` / `submitWithKey`), belirsiz sonuçta yeniden dene, `form.workflow-form`, `data-guide` hedefleri, e2e testId'leri (`error-reason`, `error-code`, `draft-lines`, `receipt-row`, `count-*`, `count-racks`, `count-missing-racks`…).
**Bilinçli farklar:** okutma alanları ortak `ScanField` (kalıp görünümü) olarak kaldı (NFC/kamera istisnası); eski seçici yazınca seçimi siliyordu — yeni seçim sayfasında seçim yalnız başka seçenekle değişir (e2e beklentisi "ürün seçilmeden ana işlem kapalı" olarak korunur). Sayfa dosyalarındaki (`shipping/page.tsx` vb.) tek tük Tailwind düzen sınıfı bu kartın kapsamı dışında.
**Doğrulama:** `pnpm verify`, `pnpm check:all`, `node scripts/changes/fold.mjs --check`; birim `receipts/actions.test.ts`. e2e (koordinatör koşar): `zz-stock-documents`, `zzz-receiving`, `zzzz-yolculuk`, `touch-screens`, `zz-kural`, `camera-scan`, `package-transfer`, `package-movement`, `first-use-guide`.
**Risk:** Yalnız arayüz; yeni eylem, yetki, okuma ya da migration yok. Stok yazımı ve idempotency aynı eylemlerle.
