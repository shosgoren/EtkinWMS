# T-429: Ekip ekranı: kişiler aktif/pasif, onay bekleyenler, davet, saha katılma QR'ı
**Faz:** 4S · **Ajan:** domain + web · **Bağımlılık:** T-423, T-421 (grup seçimi) · **Dal:** `feat/T-429-team` → `int/panel-2`
**Amaç (tek cümle):** `Ekip.dc.html` akışı: yönetici QR yazdırır, personel kendi cihazıyla okutup kullanıcı adı + parola girer, yönetici cihaz bilgisi ve 6 haneli kodla grup seçip onaylar.
**Okuma listesi (≤5):** `docs/design/source/Ekip.dc.html`, `packages/domain/src/identity/devices.ts`, `packages/db/migrations/0045_shared_devices.up.sql`, `packages/domain/src/identity/invitations.ts`
**Dokunulacak dosyalar (≤10 desen):** `packages/db/migrations/0051_*`, `packages/domain/src/identity/**`, `apps/web/app/t/[slug]/members/**`, `apps/web/app/field/**`, `apps/web/messages/**`, `docs/design/source/Giris.dc.html`, `scripts/design/port.mjs`, `tests/**`, `docs/**`
**Yapılacaklar:**
- Katılma QR'ı: alan başına tek geçerli, 7 gün, yenilenince eskisi geçersiz; belirteç URL parçasında (`#`), DB'de özet (0045 deseni).
- Personel cihazında: kullanıcı adı + parola belirle → talep (cihaz adı/model, ağ ipucu) + 6 haneli kod ekranda; onay bekler.
- Yönetici: Onay bekliyor listesi, kod eşleşmesi, grup seç → onayla (üyelik + cihaz açılır) / reddet; Kişiler aktif/pasif (pasif = oturumlar kapanır, giriş yok; hesap sahibi pasif yapılamaz); e-posta daveti grupla.
- Giris.dc.html yönetici ekranlarının alt çubuğu (repo kaynağı yenilenir, port.mjs sha güncellenir).
- Kötüye kullanım sınırları: QR başına saatlik talep sınırı, bekleyen talep üst sınırı, 3 yanlış kodda talep iptali.
**Kabul ölçütü:** int: onaysız talep giriş yapamaz; süresi dolmuş/yenilenmiş QR reddedilir; pasif üye oturumu düşer; e2e uçtan uca katılma.
**Gerekli inceleme:** security-reviewer (zorunlu: uzun ömürlü QR, kendi kendine kayıt), qa-verifier.
