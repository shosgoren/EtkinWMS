# T-1133 — Paraşüt: Etkin'in ortak OAuth uygulaması (müşteri anahtar girmez)

**Dal:** `feat/T-1133-ortak-oauth`
**Kullanıcı kararı (30 Ekim):** "Etkin TEK ortak Paraşüt OAuth uygulaması kaydeder; müşteri Application Id / Secret / Callback girmez. Bağlan = 3 adım: BAĞLAN → Paraşüt'te giriş yap ve izin ver → şirketini seç." Anahtarları sahip sunucuya girer; değer istenmez/kabul edilmez, repoya/belgeye/loga/sohbete yazılmaz.
**Neden T-1066'dan sapma:** T-1066 sırların env/ortak anahtara sabitlenmemesini ve müşteriye özel uygulamayı seçmişti (ilk müşteri kendi uygulamasını kaydetti). Yeni karar müşteri deneyimini öne alır; müşteri uygulaması "Gelişmiş" altında korunur ve önceliklidir, eski veriler değişmez.
**Kapsam:**
- `config()` çözüm sırası: kiracının kendi uygulaması (`integration_oauth_apps`) → ortak uygulama (`PARASUT_OAUTH_CLIENT_ID` / `PARASUT_OAUTH_CLIENT_SECRET`, dönüş `BETTER_AUTH_URL` + `/api/integrations/parasut/callback`, sabit ortak sürüm) → yok. `configured` ikisinden biri varsa. Ortam sırrı DB/audit/log/istemciye girmez; deneme bağlaması (state hash + HttpOnly nonce + kiracı/kullanıcı/üyelik + client_id + sürüm) aynı.
- Ekran: BAĞLAN doğrudan Paraşüt'e; anahtar alanı yok. "Gelişmiş: kendi Paraşüt uygulamanı kullan" açılır satırı (`KalipSatir`): 1 gerçek dönüş adresi salt okunur + Kopyala ("Paraşüt → Ayarlar → Entegrasyonlar → Yeni uygulama → bu adresi yapıştır"), 2 "Paraşüt uygulama kimliği" / "Paraşüt gizli anahtarı" (`KalipFormEkran` doğrulaması: boş → kırmızı + "2 alan eksik"), 3 BAĞLAN. Dönüş adresi artık istemciden alınmaz (sunucu değeri); eski yetki kodu (OOB) yalnız formdaki "Eski yöntem" anahtarıyla. "Eski bağlantı yöntemi" düğmesi kalır (parola akışına başka yol yok; kaldırma T-1137). Sağlayıcı hata kodu (`ProviderError.code`, DENIED, CONFIG…) ekranda `reasons.*`; callback yalnız sabit kodu `oauth_reason` ile taşır.
- Yaşam döngüsü kapısı: kiracı satırı yoksa bağlantı, bağlanma anını kapsayan, aynı kullanıcı/üyelikle COMPLETE olmuş ve ortak sürümlü yetki kodu denemesinden geldiyse sabit ortak sürümle açılır; eski parola bağlantısında kapalı. Migration yok.
