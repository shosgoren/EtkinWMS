2. Saha toplama `/field/pick?task=`: Okut raf (görev rafıyla eşleşmeli) → Okut ürün (`previewShippingPickAction` ile doğrulama, okutma başına temel miktar) → Miktar (sayı tuşları; okutulan barkod biriminde; aynı barkod +1; fazlası engellenir; eksikte turuncu uyarı) → ONAYLA (`confirmShippingPickAction` → `confirmPick`; anahtarlı). Bitince sıradaki toplama ya da Sevke geç.
3. Saha sevk `/field/ship?order=`: sevk alanındaki satırı seç → miktar → yükleme onayı → `postShipmentAction` (`shipOrder`); başarıda liste yenilenir; açık toplama varsa uyarı.
4. Saha sayım `/field/count?task=`: rafı okut → ürünü okut (ya da listeden seç) → sayı → KAYDET (`recordCount`); kör sayımda sistem miktarı istemciye gelmez, sayılmayan ürün uyarısı; kör olmayan oturumda fark uyarısı; bulgu (rafta kayıtlı olmayan ürün) uyarısı; oturumun tüm satırları sayılınca "Sayımı onaya gönder" (`submitCount`).
5. Yönetici sayım `/counts`: oturum listesi, yeni sayım (depo + raf kodları + kör seçeneği → `startCount` + `createCountTasks`; bilinmeyen kod varsa komut çalışmaz), fark incelemesi + Farkı onayla (`approveCount`, görev ayrılığı domain'de) + Fark fişini işle (`postCountAdjustment`) + iptal (`cancelCount`, gerekçe). Görevler ekranında Sayım süzgecinden bağlantı.
6. Bağlantılar: Görevlerim "Başla" PICK → toplama, oturumlu COUNT → sayım (toplama eksiğinden doğan oturumsuz COUNT kilitli + gerekçe); OKUT raf/ürün bekleyen toplama/sayım işine gider (bana atanmış → bekleyen kabul → üstlenilebilir → eski hedefler); Sevkiyat ayrıntısında "Sahada topla / Sahada sevk et".
