# T-1110 — Etkin doğal söyleyişleri anlar (bekleyen işler, ekli ekran adları)

**Dal:** `feat/T-1110-etkin-anlama`
**Amaç:** Kullanıcı (28 Ekim, ekran görüntüleriyle): "basılı tut konuş işlemlerin çoğunu anlamıyor — bekleyen iş var mı diyorum olmuyor, kullanıcı ayarlarına git diyorum olmuyor, ürünleri aç diyorum olmuyor; türetilebilir". Kurallı ayrıştırıcı yalnız "görev" sözcüğünü ve ekran adını eksiz/benzer yazımla tanıyordu; Türkçe ekler ("ürünleri", "ayarlarına") eşleşmiyor, "Ürünleri" sunucuda ürün adı benzerliğine düşüyordu.
**Dokunulacak dosyalar:** `docs/tasks/T-1110.md`, `docs/changes/T-1110.md`, `packages/shared/src/voice/acilis.ts`, `packages/shared/src/voice/index.ts`, `packages/shared/src/voice/niyet.ts`, `packages/shared/src/voice/niyet.test.ts`, `packages/domain/src/voice/yanit.ts`, `apps/web/app/t/*/kabuk/etkin.tsx`, `tests/e2e/etkin.spec.ts`, `tests/e2e/support/fake-voice.ts`.
**Kapsam:**
- Ekran sözlüğü (`@wms/shared/voice` `openTarget`): kök öneki eşleşmesi (ekler yutulur) + eş anlamlılar (ürün/malzeme, cari/müşteri/tedarikçi, ekip/kullanıcı/personel, fiş/belge/hareket, stok/envanter …) + alt sekme ("kullanıcı ayarları" → Ayarlar › Kullanıcılar, "tema ayarları" → Görünüm, "Paraşüt/entegrasyon" → Bağlantılar).
- Ayrıştırıcı: "bekleyen işim var mı", "işlerim", "yapılacak iş", "görevim var mı" → kişinin görevleri; ekran açma fiili sonda ya da başta, kibar ekler ("açar mısın", "-e git/geç/bak"), yalnız ekran adı ("Ayarlar").
- Sunucu: bilinen ekran adı ürün/cari benzerliğine düşmez; istemci yetkili modülü açar (yetkisizse "yetkin yok"), değilse eski modül adı benzerliği.
**Doğrulama:** birim (13 yeni cümle + 15 ekran hedefi, eski 20 ölçüm cümlesi aynı); e2e `etkin` ("Ürünleri aç" → Ürünler, "Bekleyen işim var mı?" → Görevlerim kartı; sahte ses servisinde süreye göre metin); `pnpm prepush`.
**Risk:** Yalnız niyet/yönlendirme; yeni yazma yolu ve yetki değişikliği yok (açılan adres üyenin zaten gördüğü modül).
