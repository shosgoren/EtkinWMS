# T-905: Bilgisayardan bağımsız Etkin WMS VPS yayını

**Faz:** Operasyon · **Ajan:** Codex · **Bağımlılık:** Mevcut VPS, kullanıcı otomatik yayın talebi · **Dal:** feat/T-905-automatic-deploy

**Amaç (tek cümle):** GitHub Actions üzerinden yalnız EtkinWMS VPS'sine sınırlı kimlikle exact main SHA yayın bağlantısı kurmak.

**Okuma listesi (≤5):** .github/workflows/ci.yml, .github/workflows/guards.yml, Dockerfile, docs/tasks/T-904.md, scripts/guards/protected-paths.mjs.

**Dokunulacak dosyalar (≤10):** `.github/workflows/deploy-vps.yml`, `deploy/vps/automation/**`, `docs/tasks/T-905.md`.

**Yapılacaklar:** Ayrı forced-command SSH kimliği; root-sahipli sabit Compose ve release receiver; hash, imaj kimliği, exact main SHA ve tüm CI kapıları; schema değişiminde fail-closed; sağlık başarısızlığında schema uyumlu önceki sürüme dönüş. Runtime sırları VPS'de kalır. Workflow ve sınır testleri ayrı küçük korunan PR'dır.

**Kabul ölçütü:** Yetkisiz komut/anahtar erişimi reddedilir; sınır testleri geçer; gerçek GitHub runner → VPS check doğrulanır. CI/schema kapıları kapanmadan yeni ürün sürümü yayınlanmaz. Yalnız bağlantı testi ürünün yayınlandığı iddiasına dönüşmez. Workflow korunan dosyadır: mevcut onay/inceleme kuralları atlanmaz.
